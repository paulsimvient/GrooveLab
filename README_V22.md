# Lil God Projector v2.2 — Per-Effect UADx Sends

Each instrument track now has five independent aux sends:

- Paradise Guitar Studio — ON/OFF + SEND
- Century Tube Channel Strip — ON/OFF + SEND
- Compressor — ON/OFF + SEND
- Galaxy Tape Echo — ON/OFF + SEND
- Capitol Chambers — ON/OFF + SEND

There is one shared instance of each effect. A track can feed any combination of the five effects at its own send level. Effects are parallel aux returns rather than one chained shared send.

UAD effect discovery now accepts native UADx bundles (including UA native `uaudio_` bundle naming) and rejects legacy UAD/UAD-2 DSP plug-ins. VST3 is preferred over AU.

The right-side FX BUS editor controls the shared plug-in parameters and global FX return.
