# Lil God Projector v2.6 — Euclidean All-Track Performance

EUC is now a track rhythm editor, not a drum-only page. Select any drum voice or MOOG / PROPHET / KEYS in the same bottom selector. STEPS, PULSES, ROTATE and STEP/EUCLID/HYBRID always apply to the selected target.

For melodic tracks, the piano roll is the note source. In EUCLID/HYBRID, each Euclidean pulse advances to the next note-start event (a chord counts as one event), while the contextual lower panel controls velocity, probability, repeats, octave and gate. STEP mode remains normal piano-roll playback.
