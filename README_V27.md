# Lil God Projector v2.7

This build makes instrument identity global and persistent. DRUMS, MOOG, PROPHET and KEYS are selectable from a persistent instrument dock on every page. The dock can remain attached above the keyboard or float modelessly and be dragged.

For melodic tracks, EUC now shows the piano roll and Euclidean rhythm editor at the same time. Notes define pitch/chords; Euclidean pulses define the performance rhythm. `FIT NOTES` centers the pitch range around the material.
